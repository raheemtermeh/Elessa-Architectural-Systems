# راهنمای راه‌اندازی بک‌اند Strapi سیستم‌های هوشمند معماری السا
## Strapi Headless CMS Backend for Elessa Architectural Systems

این پوشه حاوی سیستم بک‌اند کامل **Strapi** برای مدیریت کلیه داده‌های وب‌سایت السا (شامل محصولات، درب‌های اتوماتیک، کرکره‌های برقی، هندریل‌ها، پروژه‌ها، مقالات و فرم‌های استعلام قیمت) می‌باشد.

---

### ۱. نیازمندی‌ها
- **Node.js**: نگارش ۱۸ یا ۲۰
- **npm** یا **yarn**

---

### ۲. مراحل راه‌اندازی سریع در ۲ دقیقه

#### گام اول: نصب وابستگی‌ها
وارد پوشه `strapi-backend` شده و دستور زیر را اجرا کنید:
```bash
cd strapi-backend
npm install
```

#### گام دوم: ساخت کاربر ادمین و اجرای سرور
```bash
npm run develop
```
سرور استراپی بر روی آدرس [http://localhost:1337](http://localhost:1337) بالا می‌آید.  
در اولین ورود به آدرس [http://localhost:1337/admin](http://localhost:1337/admin)، فرم ساخت کاربر مدیر ارشد (Super Admin) را تکمیل کنید.

#### گام سوم: تنظیم دسترسی عمومی (Public Permissions)
برای اینکه فرانت‌اند بتواند بدون نیاز به لاگین داده‌ها را بخواند و فرم‌های استعلام را ثبت کند:
1. در پنل ادمین وارد بخش **Settings > Users & Permissions Plugin > Roles** شوید.
2. بر روی نقش **Public** کلیک کنید.
3. تیک‌های دسترسی زیر را فعال و دکمه **Save** را بزنید:
   - **Product**: `find` و `findOne`
   - **Category**: `find` و `findOne`
   - **Project**: `find` و `findOne`
   - **Article**: `find` و `findOne`
   - **Service**: `find` و `findOne`
   - **Faq**: `find` و `findOne`
   - **Global-setting**: `find`
   - **Inquiry**: `create` (جهت ثبت فرم‌های استعلام قیمت کاربران)

---

### ۳. راه‌اندازی با داکر (Docker Compose)
در صورتی که ترجیح می‌دهید از داکر استفاده کنید:
```bash
cd strapi-backend
docker compose up -d
```

---

### ۴. ساختار کالکشن‌های طراحی‌شده
- **`api::product`**: درب‌های اتوماتیک، کرکره‌ها، هندریل‌ها، مقادیر قیمت، وزن، کدهای استاندارد و پوشش‌ها
- **`api::category`**: ۴ ستون اصلی سیستم‌های السا
- **`api::project`**: نمونه‌کارهای اجراشده، سال اجرا، حجم متراژ و رضایت‌نامه‌ها
- **`api::inquiry`**: استعلام‌های ثبت‌شده با کد رهگیری و ابعاد
- **`api::article`**: مقالات وبلاگ و دانستنی‌های مهندسی شیشه
- **`api::service`**: ۴ باکس سرویس قالب فلوکس با آیکون و مشخصات
- **`api::faq`**: سوالات متداول کارفرمایان
- **`api::global-setting`**: اطلاعات تماس، ساعات کاری و آمار پروژه‌ها

---

### ۵. وضعیت اتصال در فرانت‌اند
فرانت‌اند ری‌اکت به صورت خودکار سرور Strapi را پایش می‌کند:
- هنگامی که Strapi در حال اجرا باشد: آیکون سبز در بالای سایت نمایش داده شده و کلیه داده‌ها زنده از اندپوینت‌های `/api/...` دریافت می‌شوند.
- در صورت عدم اجرای سرور: فرانت‌اند به صورت خودکار از مخزن محلی (Local Dynamic Fallback) استفاده می‌کند تا سایت بدون وقفه فعال بماند.
